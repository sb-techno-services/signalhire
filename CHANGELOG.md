# Changelog

## Expanded release

- Added private saved jobs and in-app alerts for new matching vacancies.
- Added opt-in recruiter discovery for candidate profiles, application messaging and status timelines.
- Added company website and benefits, work arrangement filtering, and a fictional posting-credit ledger.
- Added public vacancy JSON and signed publish/close webhooks with retry and delivery tracking.
- Added upgrade migrations, workflow guides and automated coverage for each new area.

## Initial MVP

- Added separate candidate and recruiter accounts, job search and vacancy management.
- Added private CV uploads, applicant review and status updates, with ownership and duplicate-submission checks.
